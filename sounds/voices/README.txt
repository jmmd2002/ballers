Drop voice lines here (.wav .ogg .mp3 .flac .m4a). They play automatically when
the ability is used, in the live game and in exported videos.

  naruto/shadow_clone_jutsu.*   "Kage Bunshin no Jutsu!"
  naruto/rasengan.*             "Rasengan!"
  sasuke/sharingan.*            "Sharingan!"
  sasuke/fireball_jutsu.*       "Katon: Goukakyuu no Jutsu!"
  sasuke/rasengan.*             (optional) when Sasuke uses a copied Rasengan
  levi/odm_gear.*               ODM gear gas shot
  levi/flurry_of_slashes.*      ODM nape slash
  beast_titan/rock_throw.*      Beast Titan roar
  beast_titan/grab.*            Zeke's scream

File name = ability name in lowercase with underscores. New fighters follow the
same pattern: voices/<fighter key>/<ability_name>.*

Sound effects live in ../sfx/. Replace any of those files to change an effect;
delete one to regenerate the default.
